## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/yourname/wildberries-parser.git 
cd wildberries-parser
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
uv sync --group dev
```

3. Установка хуков

```bash
pre-commit install
```
